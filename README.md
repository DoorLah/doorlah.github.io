# DoorLah - Official Website

Official landing page for DoorLah, Singapore's community connection app.

## 🌐 Live Site

Visit: [https://doorlah.github.io](https://doorlah.github.io)

## 📱 About DoorLah

DoorLah connects Singapore housing communities (HDB, condominiums, and private estates) - enabling neighbors to chat, discover local services, shop at neighborhood stores, and build stronger community bonds.

## 🚀 Features

- **Community Chat** - Connect with neighbors in real-time
- **Local Services** - Find trusted service providers nearby
- **Marketplace** - Buy and sell within your community
- **Local Shops** - Support neighborhood businesses
